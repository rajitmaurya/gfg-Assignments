# 🚀 MongoDB CRUD Assignment

This project demonstrates CRUD operations using Node.js, Express, and MongoDB.

---

## 📌 Features

- Connect Node.js with MongoDB Atlas
- Create Student schema
- Perform CRUD operations (Create, Read, Update, Delete)

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

---
## ⚙️ Setup

```bash
npm install
node server.js
